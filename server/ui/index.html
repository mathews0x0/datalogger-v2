Quick Tutorial

How To Pair Your RS-Core

Four short cards to get your device paired, syncing, and easy to reconfigure later.

Slide 1

What Happens On First Setup

1. Boot Into Pairing

If the device has no saved WiFi, it enters pairing mode automatically. Otherwise, hold the sync button to enter sync mode, then long-press to start pairing.

2. Join RS-Core WiFi

The device creates an open network named RS-Core-XXXX. Join it and your phone should land in the captive portal.

3. Save Credentials

Enter a device token plus the WiFi or hotspot credentials you want the device to use later for syncing.

Slide 2

Where Will You Sync?

Choose the network style you plan to use most often. You can change it later any time.

Phone hotspot keeps things portable.
Use this if you travel often, want the same setup everywhere, and don’t mind enabling hotspot only when you want sessions uploaded.
Slide 3

Use The Magic Link

Generate a token first

Create one token per physical RS-Core in Device Settings. That token identifies which account should receive uploads.

Open Auto-Setup Device

Enter the hotspot or WiFi name you chose, plus its password. The app builds a setup link that opens the captive portal with those details prefilled.

Tap the sync link while on RS-Core WiFi

The magic link fills the captive portal automatically, writes the config, then the device reboots and later syncs through the saved network.

Slide 4

How To Re-Setup Later

How to re-enter pairing with saved WiFi

Power on the device, press the sync button during the boot decision window to enter sync mode, then long-press the same button for about 3 seconds to start pairing mode and bring back RS-Core-XXXX.

Switching to another hotspot or WiFi

Once pairing mode is back, join RS-Core-XXXX again and run Auto-Setup with the new SSID and password. This overwrites the saved sync network on the device.

Do you need a new token?

Usually no. Reusing the same magic link token is fine when the same device stays connected to the same account. Create a new token only if the old one was revoked or you want a different device/account mapping.

Device behavior reminder: logging happens with radios off, then sync happens later when you intentionally bring the device into sync mode and back into a saved network.

Quick Tutorial

Understand RS-Core LED Behaviours

Use these four cards to tell normal behavior from setup prompts or real hardware issues.

Slide 1

Boot And Decision Window

Blue pulses

Normal boot confirmation. The device has powered up and is stepping through initialization.

Fast green blink

Good news: SD, IMU, and GPS all look healthy. If you do nothing, the device will continue toward logging mode.

Fast red blink or solid red

Fast red usually means SD or IMU trouble. Solid red means GPS is not healthy yet, so the device waits here until GPS recovers or you press sync.

Slide 2

Logging And Track Feedback

Yellow pulse

The device is searching for a valid GPS fix before it can log properly.

Solid green or lights off

Solid green means normal logging. If the lights go mostly dark while riding, that can also be normal stealth track mode after track detection.

Track and sector flashes

White means track found. Green, orange, and red flashes give sector feedback against your best sector data.

Slide 3

Sync And Pairing Colors

Purple

Purple indicates sync-mode WiFi work. It may be searching for your saved network or confirming that WiFi was found.

Green flashing or fading

Fast green flashing means uploads are happening. A calmer green afterward usually means heartbeat or sync succeeded.

Blue breathing or rainbow

Blue breathing means pairing mode is live. Rainbow means setup is needed, usually because there is no saved WiFi yet.

Slide 4

What Should You Do?

If you see solid red

Give the GPS a better sky view, wait for recovery, or press sync if your goal is to pair or upload instead of ride immediately.

If you see blue breathing

Join RS-Core-XXXX on your phone and continue with the captive portal or magic-link setup flow.

If you are unsure

Open Device Settings, check heartbeat status, and use the setup tutorial again. Most “strange” LED behavior is actually expected state feedback, not failure.

The LEDs are state-driven. Different colors in boot, logging, sync, and pairing are intentional and help you tell whether the device is ready, waiting, uploading, or needs attention.
